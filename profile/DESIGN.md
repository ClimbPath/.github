# ClimbPath — Design Guidelines

> Foundational visual guidelines for the ClimbPath website and mobile app.

## 1. Design Philosophy

ClimbPath combines technical precision with an outdoor, adventurous character. The visual style is modern, minimalist, and clean, with a focus on readability, clarity, and a consistent experience across web and mobile.

### Core Principles

- **Light-first:** clean white is the primary interface background.
- **Minimalism:** every visual element should have a clear purpose.
- **Consistency:** the website and mobile app should share the same visual identity.
- **Brand identity:** lime green appears across pages as a restrained accent that connects the interface to the logo.
- **Clarity:** information and interactive elements should be easy to recognize.

## 2. Colors

The palette is built around white, a lime-green accent, and a deep dark tone for occasional supporting surfaces.

| Token | Hex | Usage |
|---|---|---|
| `--bg` | `#FFFFFF` | Primary background |
| `--btn-green` | `#C1D82F` | Primary buttons and brand accents |
| `--btn-hover` | `#99AD18` | Button hover state |
| `--dot` | `#C3D22B` | Small graphic details and highlights |
| `--dark` | `#0F1219` | Footer and selected supporting dark surfaces |

### Color Usage

- White is the default background.
- Lime green should appear throughout the experience, but should not overpower the content.
- Use green to reinforce brand identity and highlight important interactions or details.
- Use `#0F1219` for selected supporting surfaces and elements—not only for the footer.
- Text and controls must maintain sufficient contrast and readability.

## 3. Logo

ClimbPath uses an existing logo. These guidelines describe how to use it rather than redesigning it.

- Use the standalone brand symbol without the wordmark where a symbol-only mark is needed.
- Keep the original proportions and do not distort the logo.
- Leave sufficient clear space around the symbol.
- Do not add unapproved effects or decorative treatments.
- Use an appropriate existing logo variant for light or dark backgrounds, where available.

## 4. Typography

ClimbPath uses a small set of typefaces for different purposes.

| Typeface | Usage |
|---|---|
| **Nunito** | Primary interface typeface |
| **Plus Jakarta Sans** | Articles and editorial content |
| **Inter** | Supplementary use where appropriate |
| **System fonts** | Native system elements and cases where platform typography is preferred |

Typography should remain readable and consistent on both mobile devices and larger screens. Use each typeface intentionally rather than mixing them arbitrarily.

## 5. Icons

ClimbPath uses a combination of filled and outline icons.

- Choose the style based on the icon's purpose and context.
- Keep icons within the same group consistent in size, visual weight, and alignment.
- Avoid mixing styles unnecessarily among functionally related elements.
- Ensure icons remain legible on both light and dark surfaces.

## 6. UI Principles

- Prefer clean layouts and a clear visual hierarchy.
- Use green selectively for important interactions and brand details.
- Avoid unnecessary decoration, heavy shadows, and excessive effects.
- Keep buttons, states, icons, and typography consistent.
- Account for touch interaction and readability in the mobile app.
- Maintain sufficient contrast and make interactive elements easy to identify.

## 7. Implementation Notes

- Keep the palette consistent across the website and mobile app.
- Use the established color tokens consistently.
- Add new colors or typefaces only when there is a clear reason.
- Preserve the core ClimbPath identity when evolving the design.
