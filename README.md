# ClimbPath

**Discover, plan, and explore via ferratas across Europe.**

ClimbPath is a community-driven platform built to make via ferrata information easier to discover and use. It brings route details, maps, community reports, and selected interactive 3D models together in one place.

## What we're building

- **Via ferrata database** — structured information to help people discover routes and prepare for their trips.
- **Maps and route details** — locations, difficulty, approach and descent information, and other useful route details.
- **Community contributions** — users can suggest new routes, submit corrections, share photos, and report conditions.
- **Interactive 3D models** — selected routes and rock faces can be explored in 3D.
- **Planning tools** — search, favourites, and features that help users organise their next adventure.

## Our mission

We want to make via ferrata information more accessible, organised, and useful for the climbing community. We are starting in the Czech Republic and gradually expanding the database across Europe.
